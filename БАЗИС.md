## 0. Режим работы скрипта
FileOptions = 'Настройки.xml';
MakeProps();
try { Loaded = Action.Properties.Load(FileOptions); } catch(e){ Loaded=false; }
Action.OnFinish = function(){ SaveProps(); }   // НЕдостаточно! см. п.1
... построение ...
Make();
Action.Continue();

ВАЖНО: глобальные переменные объявлять var ДО первых вызовов.
Function-объявления поднимаются (hoisting), а инициализаторы var — НЕТ.
Порядок «Make() ... var OBJ={...}» даёт TypeError: Cannot set property of undefined
на первом запуске, и только на первом.

## 1. Сохранение настроек
Action.Properties.Save вызывается в OnFinish, т.е. только при «Закончить».
Если пользователь пересчитывает модель кнопками / сменой параметра и НЕ завершает
скрипт — файл не перезаписывается, введённые пути к фурнитуре СЛЕТАЮТ.
Решение: SaveProps() в конце каждой Make() + SaveProps() в OnClick каждого
селектора файла + отдельная кнопка «Сохранить настройки».
Флаг Making=true внутри Make() — защита от рекурсии (Prop.OnChange -> Make).

## 6. Различать «укорочение» и «рассечение»
Препятствие, выходящее на КРАЙ панели = укорочение (безопасно).
Препятствие ПОСЕРЕДИНЕ на всю ширину = рассечение на две части (конструктивно
недопустимо для ЛДСП, допустимо для ЛХДФ 3 мм).
Признаки: fA=(a2-a1)>=(pu2-pu1)-0.5 ; iA=(a1>pu1+0.5 && a2<pu2-0.5)
Предупреждение выдавать только при (fA&&iB)||(fB&&iA).

## 7. Фурнитура
Файл:  f = OpenFurniture('путь.fr3d')
База:  f = propFurn.Value ; проверка выбора: f.EncodeToString().length>8
Тип:   dm = f.DatumMode  (0=None,1=Face,2..5=FaceFace/…,6=Box,7=Scheme)

Методы:
  f.Mount1(panel, x,y,z, angle)          — на плоскость одной панели
  f.Mount(panelA, panelB, x,y,z)         — на стык двух панелей
  f.MountScheme(panelA, panelB, FurniturePosition.Inside, vec)
  f.MountBox(originVec, sizeVec, axis1, axis2)  -> комплект ящика
  f.Make(t1,t2) / f.Make()               — резерв, геометрия БЕЗ присадки

ПРАКТИКА: привязка НЕ задаёт метод жёстко. Полкодержатель с DatumMode=2
встал через Mount1. Опора с DatumMode=0 не встала НИ ОДНИМ методом — нужен
аналог с Face. => писать перебор методов (Mount1 -> Mount -> Mount1 на вторую
пласть -> Make(t,t) -> Make()) и считать, какой сработал.
Врезной вариант опоры/полкодержателя: второй панелью передавать боковину,
а не полку — сверловка тогда уходит в нужную деталь.

## 8. Блоки и анимация
var b = BeginBlock('Имя'); ... EndBlock();
b.AnimType = AnimationType.Box | DoorLeft | DoorRight | DoorFlap   // список
получать дампом: for(var k in AnimationType) — документация неполная.
Пустой селектор ящика => MountBox не вызывается => блок «ящик» движется
на толщину панели без содержимого. Симптом «ящик не выезжает» = путь не задан.
Поворот стены/секции: b.RotateY(-90); b.TranslateGCS(NewVector(X,0,Z));
Двери: BeginBlock на дверь, фасад+петли ВНУТРИ блока, затем AnimType.
Ящик: BeginBlock -> MountBox -> фасад -> EndBlock -> AnimType=Box.

## 11. Приёмы, которые прижились
- Перемычка ЛДСП < 10 мм — брак. Вентиляционный выход: панель УКОРАЧИВАТЬ
  до нужной глубины, щель открыта к кромке, а не фрезеровать окно с 4 мм краем.
- Паз под трубу в полке открывать к ЗАДНЕЙ кромке (полка вставляется спереди,
  труба входит в открытый паз). Открытый к переду паз не даёт задвинуть полку.
- Отступ ручки считать от КРОМКИ до КОНЦА ручки, а не до центра:
  v = верх - отступ - межцентровое/2. Иначе скоба выступает за фасад.
- Лючки доступа параметризовать строкой: «секция:элемент:u:v:Ш:В»,
  элемент = зад|задниз|лев|прав. Не зашивать координаты в код.
- Все препятствия (канал, фартук, коммуникации) задавать прямоугольниками в
  параметрах и проверять пересечение с каждой панелью автоматически.
